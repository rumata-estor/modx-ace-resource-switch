# MODX Ace Resource Switch

Переключение редактора **содержимого ресурса** между **CKEditor** (визуальный режим) и **Ace** (режим кода) штатным флажком **«Использовать HTML-редактор» / richtext** в MODX Revolution. Без изменения ядра и без транспортного пакета.

[English README](README.md)

## Совместимость

Проверено на **MODX Revolution 3.2.4-pl**, **Ace 1.9.10** и **CKEditor** (`ckeditor.version = 1.4.7-ce` на тестовом сайте). Другие визуальные редакторы и MODX 2 **пока не проверены**.

Нужны установленные и включённые дополнения Ace и CKEditor.

## Установка

1. В **Системных настройках** установите `use_editor = Да`, `which_editor = CKEditor` и `which_element_editor = Ace`. При необходимости проверьте переопределения в контекстах.
2. В разделе **Элементы → Плагины** создайте плагин `AceResourceEditor`.
3. Скопируйте в него содержимое файла [`AceResourceEditor.plugin.php`](AceResourceEditor.plugin.php) **без добавления `<?php`**.
4. Назначьте событие **`OnDocFormPrerender`** и включите плагин.
5. Очистите кеш MODX, перезагрузите страницу админки и проверьте переключение флажка **«Использовать HTML-редактор»** на тестовом ресурсе.

При `richtext = 1` работает CKEditor, при `richtext = 0` — Ace. Перезагрузка страницы для переключения не требуется.

## Особенности

- При переключении через CKEditor **без редактирования** исходный HTML восстанавливается побайтово, включая комментарии и переводы строк.
- Если **редактировать в CKEditor**, он может изменить форматирование HTML, пробелы и комментарии. При возвращении в Ace плагин предупреждает об этом.
- Сохранение ресурса берёт содержимое активного редактора.
- Плагин работает с содержимым стандартных ресурсов, не затрагивает TV и редакторы элементов. Файлы Ace и CKEditor не изменяются.

Для удаления отключите или удалите `AceResourceEditor` и очистите кеш MODX. Системные настройки при необходимости восстановите вручную.

## Тесты

`node tests/switch.test.cjs` (Node.js 18+, дополнительных пакетов не требуется). Проверяются переключение, сохранность HTML, передача изменений и отложенная инициализация CKEditor. Перед использованием на рабочем сайте рекомендуется дополнительно проверить интерфейс.
